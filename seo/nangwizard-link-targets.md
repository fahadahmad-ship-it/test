## Method
- 550 already-built domains loaded from the client sheet as an exclusion set
- **66 candidates** verified across 6 parallel agents
- Each: Ahrefs dup + Semrush dup + Semrush AS + Semrush All traffic + outbound dofollow % + out:in ratio + a top-pages content check to judge real topical fit (not the vendor's category label)
- Semrush dup filter validated against a known-built domain before any negative was trusted
