# Domains needing backlink data

**334 referring domains, 3,522 backlinks.**

Every one of these has a verdict based only on domain authority, backlink
count, IP address and domain name. **Not one of their links appears in the
50,000-row export**, so there are no anchors, no target URLs and no
redirect data behind any of them.

They are 0.3% of the profile by volume, but they are the only unresolved
part of the audit. Every correction that reversed a verdict in this set —
`appsupports.co`, `leafysouls.com`, `thecompleteportal.com`,
`cloudaicrypto.com`, `illuminatelabv.com` — came from exactly this gap.

## Columns needed

| Column | Why |
|---|---|
| `source_url` | Distinguishes a real post from archive pagination — that artefact alone caused four wrong verdicts. |
| `anchor` | Branded vs exact-match commercial is the core anchor test. |
| `target_url` | Deep relevant article vs bare homepage. |
| `nofollow` | Nofollow passes no equity, so there is nothing to disavow. |
| `redirect_url` | **The one that matters most.** Reveals affiliate routing — this is how `hexcolor.co` and its 1.1M links resolved. |
| `response_code` | The redirect-liveness check, skipped throughout for want of it. |
| `external_num` | Outbound-link count on the linking page. |
| `page_authority_score` | Page-level authority, distinct from domain. |

Semicolon-delimited output, header row included, saved as
`semrush_backlinks_filtered.csv`.
