## THE 5 BACKLINKS

### BACKLINK 1

| Field | Value |
|---|---|
| **Target URL** | `https://3king.cc/ban-ca` |
| **Anchor text** | **game bắn cá đổi thưởng 3King** |
| **Anchor type** | Partial-match, brand-qualified |
| **Target keyword** | game bắn cá đổi thưởng |
| **Semrush volume / KD / CPC** | 8,100 · KD 49 · **$2.16** |
| **Placement type** | VN gaming/betting vertical — dedicated review page |
| **Page status** | Exists (UR 4.8) — **retitle required before placement** |

**Why selected:** This is the **only non-brand commercial keyword in the entire
account whose SERP contains legitimate ranking websites.** I checked the live
Semrush SERP: `gamevui.vn` (#6), `gameshub.com/vn/nha-cai-ban-ca-uy-tin/` (#7)
and `ica.net.vn` (#10) all hold real positions. Every other commercial term
tested — `nổ hũ đổi thưởng`, `game nổ hũ đổi thưởng`, `game đổi thưởng` — returns
hacked foreign domains serving `/vi-vn/` paths, where no legitimate site can
compete. It also carries the **highest CPC in the dataset at $2.16**, which is
the market pricing genuine deposit intent, and KD 49 is reachable.

**Why this anchor:** Brand-qualified rather than bare exact-match. The profile has
only ~16 countable links; a bare money anchor is over-optimisation shape for no
gain. Leading with the category and closing with the brand reads as a product
name, not a paid insertion.

**Blocker:** `/ban-ca` is currently titled *"Bắn cá online – Chơi bắn cá trực
tuyến **miễn phí** HOT nhất"*. It advertises **free** play while the keyword means
**real-money prize exchange**. This is almost certainly why 6 previous links to
this page produced nothing. Fix the title/H1/intro first.

| **Anchor text** | **3King** |
| **Anchor type** | Branded (exact brand token) |
| **Target keyword** | 3king |
| **Semrush volume / KD / CPC** | 9,900 · KD 70 · $1.50 |
| **Placement type** | VN gaming/tech editorial — in-body brand mention |
| **Page status** | **Ready — place now** |

**Why selected:** A **DR 0** domain (`3king-game.com`) currently holds **#1** on
your own brand name; `3king-game-mobile.com` (DR 3) holds #2; `3king.cc` (DR 19)
is #3, taking roughly **7%** of its own brand SERP. Losing to a site with zero

full rate, unlike anything non-brand.

string is already the largest spam fingerprint pointing at you — 40 referring
domains, Ahrefs `is_spam=true`, and only **2 dofollow**. Using it would place a
good link inside an existing junk cluster. For comparison, the clone wins with
319 referring domains on the clean anchor `3KING` (1,892 dofollow) against your 2.

**Why selected:** This is **your own promotion** and a competitor page
(`3king-game-mobile.com/khuyen-mai-3/`) ranks for it while your existing promo
page does not. Highest-converting intent on the site — someone searching a

in front (entity signal) while carrying the exact query term.

**Two blockers:** "30k" appears nowhere in the page title or copy, so it cannot
rank for the term as-is. And **confirm the offer is still running** — a permanent
backlink to an expired promotion is wasted. *Volume caveat: Ahrefs puts this at
10/mo against Semrush's 1,900 — a 190× spread. Treat the prize as a range.*

### BACKLINK 4

| Field | Value |
|---|---|
| **Target URL** | `https://3king.cc/tai-app` |
| **Anchor text** | **tải game 3King** |
| **Anchor type** | Branded + transactional |
| **Target keyword** | tải game 3king |
| **Semrush volume / KD / CPC** | 9,900 · KD 62 · $0.62 |
| **Placement type** | App aggregator listing (`apkcombo.com`, `apkpure.com`) — developer/website field |
| **Page status** | **MUST BE BUILT** — does not exist |

**Why selected:** Download is the highest-LTV conversion in this vertical, and it
is the one intent you have **no page for at all**. Your homepage title contains no
`tải`, `APK`, `Android` or `iOS`. The clone beats you here specifically because it
runs a dedicated `/tai-ngay-2/`. This is the single genuine architecture gap in
the site.

**Why this placement type:** App-aggregator listings are **self-owned**, so vendor
non-delivery is structurally impossible — and the previous campaign failed at a
96.9% non-delivery rate. `apkcombo.com` (DR 73, ~37,000 VN visits) and
`apkpure.com` (DR 85, ~425,000 VN visits) both appear as 3king.cc's own organic
competitors, meaning they already rank for your terms. Accept the listing even if
the developer-URL field is nofollow — this slot is bought for brand-SERP control
and referral traffic.

**Why this anchor:** Carries download intent plus the brand token. Note the clone
holds 279 referring domains on this exact string, so do not repeat it at volume —
one instance.

*Volume caveat: Ahrefs says 300/mo against Semrush's 9,900. Largest tool
disagreement in the account. Do not forecast revenue from this one.*

## PLACEMENT CRITERIA — ALL 5, PASS/FAIL

Vietnamese language · VN audience ≥60% · gaming/entertainment/tech vertical ·
Ahrefs DR ≥25 **and** linking page organic traffic ≥50/mo · indexed before payment ·
link in body prose within first 60% of article · dofollow (except Backlink 4) ·
≤25 external outbound links on page · ≤3 external gambling links on page.

**Verified prospects:** `voz.vn` (DR 60 — confirmed linking to competitor
`topnohu.com`) · `forumketqua.net` (DR 45) · `topnohu.com` (DR 42) ·
`kqbd.mobi` (DR 38) · `apkcombo.com` / `apkpure.com` (Backlink 4).

**Never buy:** compromised VN government/university hosts, the hacked `.edu`/`.org`
injection cluster, named link vendors already in the profile, or anything from the
previous vendor.

**Payment:** 0% on claim · 40% day 14 · 30% day 60 · 30% day 90. Per verified
placement. Day-0 audit must find the link in **raw HTML before JS execution**.
