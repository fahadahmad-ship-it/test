# Project Rules

## No Artifacts / Designs

Do not create, publish, or share Artifacts (via the `Artifact` tool) or
Design canvases (via the `design` skill) in this repository, in any
thread or session, under any circumstances.

- Do not call the `Artifact` tool for any purpose (publish, update, etc.).
- Do not invoke the `design` skill to create design canvases.
- Prefer plain text, code, or files written directly to disk (e.g. `.md`,
  `.txt`, source files) instead of artifacts, even when an artifact would
  normally be the default choice for a deliverable.
- This applies regardless of how the request is phrased (e.g. "make a
  report", "show me a page", "create a mockup") — if it would normally
  produce an Artifact or design canvas, do it as a plain file instead.

This rule applies to every session/thread that works in this repository.
