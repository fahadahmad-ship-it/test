NFG's headline "Authority Score 36 / rank 2-of-10" is recency-inflated, not earned. Disavow triage — hard vs review

Two distinct actions. Only the explicit-scheme set is a hard disavow; the low-AS tail is a manual review queue, not an auto-disavow — disavowing genuine-but-weak domains destroys value.

⊘ HARD disavow
~84
Domains · action: disavow

Explicit PBN / link-selling anchor domains (59 "buy backlinks / premium pbn" + "manual outreach" set) plus the two-IP PBN cluster (42 domains). Overt scheme fingerprints — safe to disavow.

⚠ REVIEW — do NOT auto-disavow
127
AS 0–2 domains · action: manual review

The low-authority (AS 0–2) tail. Low AS ≠ toxic — many are small but legitimate. Each needs a human check before any disavow decision; auto-nuking this set would remove genuine links.

Why the split matters: colour is backed by an icon and an explicit action label so the hard-vs-review distinction never rests on hue alone. The 127 AS-0–2 domains overlap the toxic tail but are a review queue, not a disavow list.
